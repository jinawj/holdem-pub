# AI v3 플레이 스타일·성격 설계 (초안, 2026-11-26)

> 상태: **1차 구현(2026-11-27)** — 축 6개(tight·aggro·bluff·sticky·trap·limp)와 스타일 9종(`src/ai/v3/style.ts`, config `AI_V3.styles`). 아직 안 한 것: balance·sizing·tilt·fearLeader·donk 축, 압박형 칩리더, 중급 '레귤러 지망생'·'틸트형'. v3를 앱에 연결할 때 v2의 습관 라벨(habits·leaks·텔)은 제거하고 이 체계로 바꾼다.
> 근거: 사용자 요청 + 리뷰어(Sonnet) 제안 3회분.

## 1. 원칙
- **실력(레벨)과 스타일은 따로.** 레벨은 '무엇을 보느냐·얼마나 정확하냐'(이미 구현), 스타일은 '같은 판단에서 어느 쪽으로 기우느냐'.
- 스타일은 개념을 끄지 않는다. 임계값·빈도·크기만 민다 → 고수 스타일은 '다르지만 여전히 강함', 하수 스타일은 '사람다운 구멍'.
- 스타일 효과는 **이름 붙은 축(숫자)** 몇 개로만. 축 값은 config 한 곳(`AI_V3.styles`).
- 같은 스타일이라도 레벨이 높을수록 극단값을 덜 쓴다(고수 LAG는 하수 매니악보다 훨씬 덜 무모).
- '기계라서 하는 행동'(판단과 반대인 드문 행동, 매번 같은 크기)은 스타일로도 허용하지 않는다.

## 2. 스타일 축 (모두 0이 표준)
| 축 | 뜻 | 어디에 걸리나 |
|---|---|---|
| tight | 참여 범위 (−: 루즈, +: 타이트) | 오픈·콜드콜·BB 수비 범위 배수 |
| aggro | 공격성 (콜 대신 벳·레이즈) | 3벳 비율, C벳·배럴 빈도, 레이즈 vs 콜 비율 |
| bluff | 블러프 빈도 | 레인지 브레인 블러프 몫(Bb) 배수, 3벳 블러프 |
| sticky | 끝까지 따라감 | 벳 받았을 때 계속 확률, MDF 수비 배수 |
| trap | 강한 패 숨기기 | 슬로플레이·체크레이즈 비율 (리버 넛 체크는 금지 유지) |
| balance | 레인지가 캡되지 않게 | 강한 패 일부 체크, 약한 패 일부 레이즈, 크기 섞기 |
| sizing | 크기 버릇 | 작게 자주 / 크게 양극화 / 강할수록 크게(하수 텔) |
| tilt | 큰 팟 잃은 뒤 흔들림 | 몇 핸드 동안 tight·aggro·sticky 이동 |
| fearLeader | 커버하는 칩리더 앞 위축 | 생존 프리미엄 배수 |
| limp / donk | 하수 버릇 | 림프 비율, 레이저 앞 리드 비율 |

## 3. 스타일 목록 (초안)
### 고수(Lv7~10)
- **정석형(균형)**: 모든 축 0, balance 높음. 강한 패도 일정 비율 체크(턴 체크 레인지의 약 20%), 약한 패 체크레이즈 5~10%, 크기 2~3종 섞기. "읽히지 않는 상대".
- **타이트 공격형(TAG)**: tight +, aggro +. 좁게 들어오지만 들어오면 3벳·큰 크기. 레이즈 받은 원페어는 확실히 접음. 사람이 블러프하기 어려운 상대.
- **루즈 공격형(LAG)**: tight −, aggro ++, bluff +. BTN/CO 오픈 50%+, 3벳 블러프 6~8%(A5s~A2s·K9s), 플랍 체크레이즈·스탭 많음. 멀티웨이에선 자제.
- **함정형(트래퍼)**: trap +, balance +. 드라이 보드·공격적인 상대일 때만 넛 패의 약 20~25% 플랍·턴 체크 → 리버 체크레이즈 5~10%. 리버 넛은 여전히 벳.
- **압박형(칩리더 성향)**: 칩리더일 때 중간 스택 상대로 오픈 넓게(2.2BB), 22~30BB 오프너에 3벳 8~10%. 숏스택이 뒤에 여럿이면 셔브 대신 작은 오픈.

### 중급(Lv4~6)
- **레귤러 지망생**: TAG를 따라 하지만 덜 정확(푸시/폴드 표를 못 외워 K9o·A5o를 7~11BB에서 올인).
- **콜 경향**: sticky +. 탑페어 이상이면 벳을 맞아도 15~25%는 리버까지.
- **겁 많은 타입**: fearLeader +, tight +. 칩리더 앞에선 이득 있는 올인도 접음.
- **틸트형**: 30BB+ 팟을 잃으면 3~5핸드 동안 오픈 +5~8%p, 3벳 +3%p, 콜 임계 완화.

### 하수(Lv1~3)
- **입문자**: limp +, sticky +. 림프 후 레이즈에 폴드, 오픈 크기 2.5~4BB 들쭉날쭉(강할수록 큼).
- **콜스테이션**: sticky ++. 약한 페어로도 리버까지 25~35%. 단 승률 5% 미만 에어 콜은 금지.
- **올인맨**: aggro ++(숏스택에서 특히). 하이카드 두 장·아무 A로 푸시.
- **겁쟁이**: 큰 벳 앞에서 보드가 무서워 보이면 약한 페어 폴드 약 15%.
- **동크형**: donk +. 맞으면 레이저 앞에서 먼저 벳.

## 4. 측정·검증
- 스타일마다 `ai-arena` 링에서 표준 v3 대비 bb/100 (고수 스타일은 표준과 비슷하거나 그 이상이어야 함, 하수 스타일은 손해가 '이름 붙은 구멍' 자리에서 나와야 함)
- `ai-defend-report`·포스트플랍 통계로 VPIP/PFR/3벳/C벳/WTSD가 스타일 목표 범위 안인지
- 리뷰어(Sonnet, 노력 중간)에게 "이 스타일이 실제 그런 사람처럼 보이나"를 판정시킴

## 5. 앱 연결 때 할 일
- v2 `habits`·`leaks`·`tells`·personas.json 성향 제거 → v3 `V3Profile.style`
- 난이도 배정: 보통(Lv3~7, 하수·중급 스타일 섞기), 어려움(Lv5~8), 매우 어려움(Lv7~10, 고수 스타일 섞기)
- 저장 형식: `GameSave`에 v3 프로필·메모리(optional) 추가, 예전 저장은 v2로 열거나 v3로 변환
